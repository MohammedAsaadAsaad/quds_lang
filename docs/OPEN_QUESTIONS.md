# Language design status

Quds 1.2 closes the language design. The grammar, the single meaning of each token, evaluation order, the Dart 3.13 parity table, the project layout, the diagnostic registry, the source-map encoding, and the macro sandbox are in `QUDS_LANGUAGE_SPECIFICATION.md`. They are not an invitation to add a second rule.

The resolutions that used to be listed here as open questions now live in that file:

- Named-argument blocks are all-label blocks. `map:` and `set:` are collections. Any other legal argument block is a collection-element block. `test` and `group` are declarations, so a test body is not a collection.
- Bare `name = expr` assigns a visible mutable binding, rejects a visible immutable binding, and otherwise declares an immutable binding. A same-name local is `shadow` or `shadow var`.
- `readonly` qualifies one reference. `to` converts. `to?` converts safely, including to a nullable target.
- Omission is `missing`. Overloads are compile-time and lower to mangled Dart names. Defaults run after supplied arguments, in declaration order.
- `return` exits a function. `result` finishes `do:`. Postfix `?` propagates `Result`. Prefix `?` on a collection element omits null. Dot shorthand is `.member` and `.new`.
- Records, holes, ranges, `with`, and `capture` keep the meanings in the token table.
- Null-aware elements, dot shorthands, private named parameters, and primary constructors are available through the spellings in the parity table.

A program that can be parsed in two ways is a compiler bug or a required rejection.

## Historical implementation notes

The notes below accumulated during earlier milestones. They contain obsolete
limitations (including the original non-launching debugger and VM-only target).
They are historical context, not the current supported-feature list. Consult the
active plan, feature-specific documents and VALIDATION.md before relying on them.

The language rules above are settled. `MVP_0.md` lists the slice that compiles and runs. These design rules are still rejected or only partly lowered:

- `await all` and `task group` start every child that has already been entered, and report the first source-order failure (`TaskFailed` for a group). A child that throws before returning requests cancellation, and later children are not entered. An already-running Dart future is not aborted.

`use "file.quds" show name` and `hide name` bind only the selected public names. A `show` name that the library does not define is `E200`. `use "file.quds" as prefix` binds `prefix.name`, and the same form works for `dart:math`. `use quds:core hide Ok` removes that prelude name. `use quds:name` loads that SDK library. `use quds:name::section`, and the same suffix on a relative, `package:`, or `generated:` library, binds that section and every section named `section::child`. `use quds:name::section::child` binds the narrower section. A missing section is `E900`. A column-0 `:: section` opens a section, `:: section::child` opens a nested section, and a bare `::` returns to the root. Sections in one file stay one library. `use quds:core` also imports its collection aliases and types: `Array`, `Dict`, `HashSet`, `Stack`, `Queue`, and `Bag`. `use quds:ext` imports extensions on `String`, `List`, `Map`, `Set`, `int`, and `double`. `use quds:math` re-exports `dart:math` and adds the mathematics Dart does not provide, such as `ln`, `sinh`, `gcd`, `mean`, `Complex`, `Vec2`, `inverse`, `qr`, `eigenSymmetric`, `svd`, `studentCdf`, `fft`, `eigenvalues`, `adaptiveIntegral`, `besselJ`, `primesUpTo`, `gmres`, `lambertW`, and `fraction`. Unprefixed `log` stays the logger, and unprefixed `min` and `max` stay the language functions. A definition inside an SDK library opens a read-only `quds-sdk` document. `show` and `hide` cover the prelude and those names. A missing `quds:` library is `E900`. The generated file imports `quds_<name>.dart` written beside it. `export "file.quds" show name` re-exports only that name. `part` and `part of` share one privacy scope, so a part may read a private field of its library. A private member used from another library is `E206`. A protected member used outside the library and its subtypes is `E207`. A missing part file is `E900`. A `part of` that does not name the parent, or a parent part whose file names a different library, is `E903`. `quds.yaml` `language:` other than `1.2` is `E901`. A `# quds:` comment does not select a version. `quds migrate` leaves a `quds.yaml` that names a version other than 1.2 unchanged, and does not rewrite its `.quds` sources. A missing `quds.yaml` is written as `language: 1.2`. There is no syntax rewrite from an older version. `@Reflectable` emits a const map with the public fields, a separate `private` list, and `typeParameters`, and `qudsReflectable` lists those maps. `quds build` stores a content hash of the source and its imported `.quds` files in `.dart_tool/quds/cache/`. An unchanged build leaves the generated file untouched. Changing an imported library or a macro in the same source rebuilds the affected output. `quds build --watch` rebuilds when one of those files changes. The generated `.dart` runs with the Dart VM and does not import the Quds package. `use package:name` loads `lib/name.quds` and emits `import 'package:name/name.dart'`. `use package:name/src/util` loads `lib/src/util.quds`. A missing package library is `E900`. A `package:` import compiled from a string, with no package root, still emits the URI as written. `use generated:user_models` loads `lib/generated/user_models.quds` and emits a `package:` import under `generated/user_models.dart` using the pubspec name. A macro that expands itself or a peer is `E904`. A string passed to `builder.addMethod` is `E905`. `DateTime`, `Random`, `Stopwatch`, `Platform`, `Isolate`, `HttpClient`, `Socket`, `WebSocket`, and `InternetAddress` inside a macro are `E905`. Expansion past depth 8 is `E906`. More than 1000 declarations from one annotation is `E906`. `@GenerateModel` writes a deterministic `value class` to `generated/<name>.quds` and a source map back to the annotation. A second build writes the same bytes. A generated name that already exists, or two generators that write one file, is `E904`. Removing the annotation deletes that previously generated file. `declare` copies a method to a top-level function with `builder.addFunction`. `define` copies methods, fields, properties, and constructors. A class with a `call` method is invoked by calling the instance. A generic class and named arguments are accepted. `protected` is emitted as `@protected` when the package depends on `package:meta`, and as a documentation comment otherwise. `quds lsp` answers definition and rename. `quds debug` binds a breakpoint to the statement on a line and does not launch a program. `mapStack` rewrites a frame whose generated line hits the map and leaves a frame that does not. A web stack is two maps applied in order. `definitionAt`, `renameAt`, and `breakpointAt` answer a `.quds` position. `quds lsp` and `quds debug` use those answers. They do not launch a program, and hot reload stays with Flutter. `quds format` parses the file, then rewrites indentation outside `"""` and `'''` to two spaces. A comment, a documentation line, and the interior of a multiline string stay as written. Trailing whitespace outside a string is removed, and the file ends with a newline. Formatting the result again leaves it unchanged. A line longer than 80 columns breaks after the last comma that still fits, outside a string or a comment. A comment and the interior of a multiline string stay on one line. `quds doc` lists `///` lines. `quds doc html` writes one HTML page of those lines. `quds doc test` compiles and runs a fenced example. A `[Name]` that is not a top-level function or class in that file is `E200` with the message `Broken link: Name`. An example that does not compile or does not run exits 65. `assert` follows Dart: `--no-enable-asserts` skips the statement, so a side-effecting condition does not run, and `--enable-asserts` runs it. `quds benchmark` runs the program both ways. Different stdout fails, and a measured time above the given baseline is a regression. A bare function name used as a statement is `E110` and the message names `()`. `require` and `check` run in both modes. A `const` binding makes a nested list, map, set, or const constructor call constant. An ordinary list binding stays mutable. A constructor that is not `const`, and a `const` constructor with a body, are rejected. `batch` holds reactive notifications until the suite exits, then flushes once. `watch` disposes its subscription when the enclosing scope exits. A computed value that reads itself while it is already evaluating throws `CycleError`. A static computed cycle warns `W007`. Typed `catch` clauses run in source order, and `finally` still runs after `rethrow`. `catch name, stack` binds the `StackTrace`. `rethrow` outside `catch` is `E107`. A `var` parameter can be reassigned, a closure sees that binding, and the caller's binding stays unchanged. A lambda may be nested, may use an indented body, and may `await`. The closure reads a mutable binding's current value. A range walks downward when the end is below the start. A function type is `(parameters) -> Type`, including a nullable function and a `Future` return. An empty list uses the expected `List` type, and a lambda parameter with no expected type and no numeric use is `E302`. A type parameter bound may be an intersection, a call infers that parameter, and an override whose return type does not match is `E300`. A `task group` may contain a nested group. An empty `map:` or `set:` uses the expected type, and a repeated key keeps the later value. `yield` inside `finally`, `yield*`, and an async generator error follow Dart. A default runs only when its argument is omitted, after the written arguments, and may read an earlier parameter. Destructuring assigns an existing mutable name and reads the whole right side first. A mixin member whose signature does not override the previous one is `E300`. A singleton initialization cycle is `E707`, and each isolate has its own instance. A list or set element written `value for name in iterable if condition` builds the collection immediately: the iterable runs once, a false filter skips the element, and a nested comprehension is a comprehension inside another. A `sync*` generator stays lazy until it is iterated. `??=` writes a nullable binding only when it is null, and the right side stays unevaluated otherwise. `else` after `catch` runs when `try` finishes without entering `catch`, and `{age=}` shows the expression text with its value. `by lazy` stores the first `result`, an extension `property` is a getter, `call` makes a value callable, and `once` runs on the first reach of that function activation. A local function sees the enclosing bindings and may call itself. `nameof` yields the path text and does not evaluate it. `require` and `check` include that condition text when the message is omitted. `event` is subscribed with `add`, and `raise` belongs to the declaring class. `where T is Numeric` means `T extends num`. `deconstruct()` with a record result is read by parallel assignment. A local is promoted after `!= null`, `== null` on the other branch, and `is Type`; a later assignment drops that promotion. A nullable receiver used directly is `E308`. Nested `>>` and `>>>` close type arguments. A `readonly` list or member yields a `readonly` view, and a nested write is `E307`. `List`, `Set`, `Map`, and `String` methods such as `add` are the Dart methods, so one alias can mutate the shared object. Postfix `?` outside a `Result` function is `E600`, and a mismatched error type is `E601`. `use dart:ffi` accepts `Pointer` and the native ABI types; a web `when` does not emit that import. `quds get` writes `pubspec.lock`. A non-empty list, set, or map uses the expected element type when every element fits it. An extension on a nullable type is callable on that nullable receiver. A `for` binding is fresh per iteration, so a closure stored from the loop and called afterward sees that iteration. An async callback reads the mutable binding's current value. `type Name wraps Type` rejects a constant that fails `require` with `E401`, throws at runtime for a non-constant failure, and has no bypass constructor in Quds. A `readonly` `List`, `Set`, or `Map` that crosses a function boundary is an unmodifiable view, because Dart cannot spell `readonly`. Passing that reference to a mutable collection parameter is rejected. `is` and `as` test and cast at runtime. `await all` reports the first source-order failure when more than one child fails. A list literal may cross `await isolate`, and a captured local is `E805`. A `sealed class` match covers its same-library subtypes, and a subtype in another library is `E703`. `Ok` and `Error` patterns read a `Result`, including a nested `Result`. Two imports of one name are `E204`. An annotation stays on a declaration. A parse error is `E100`. After one parse error, parsing continues at the next line and every recorded parse error is reported. Missing tokens are not invented. A nullable parameter keeps `?` in the generated Dart signature. `Column:` with a nested `children:` block is a call, and `map 3` is a call.

`log.debug`, `log.info`, `log.warning`, and `log.error` take a message and an optional `data:` value. `log.minimum` filters by `debug`, `info`, `warning`, then `error`. `log.sink` replaces the writer. A map key `secret`, or a key ending in `_secret` or `.secret`, is written as `***`. A sink exception propagates. `property`, `operator`, `private` / `protected` / `readonly` methods, `init`, `factory init`, and `const init`, `if value is Pattern`, `if let`, `defer`, `using` / `using async`, `static` members including `static var`, `part` / `part of`, and constant `when` / `use when` are implemented. Patterns in `match`, `if is`, and `if let` include or, and, relational, list rest, map, record, cast, null-check, and null-assert. Generic classes and functions, a single bound, variance (`E304`), generic extensions, `await all`, `await isolate` (`E805` for a captured local), `task group` / `spawn` (`E107` outside the group), `noSuchMethod` on a `dynamic` receiver, `symbol`, and `require` / `check` / `assert` are implemented. An intersection parameter lowers to `T extends` its first type, then checks `is!` for each later part. `config` reads the process environment, then the `config:` map in `quds.yaml`, then the source default. The environment name is the dotted name in upper case with `.` replaced by `_`. A secret has no source initializer, and a secret literal is `E908`. A missing required value throws `StateError` at the first read. `annotation Name(parameters)` is a const class. `@Name(...)` arguments are named constants (`E401` otherwise, `E500` when a required argument is missing). A value-class `copyWith` copies every instance field, including one assigned in the constructor body. An omitted argument keeps the current field. `platform` is `"vm"` for `quds build`. A `when` condition that is not a constant boolean is `E902`. A file that contains both `part` and `part of` is `E903`. The unselected `when` branch is not type-checked. Aliases, extension types, the Dart class modifiers, and the diagnostic registry are implemented. An integer outside the JavaScript safe range stays exact on the VM, and Dart's web compiler rejects it. That behavior is covered by `test/language_test.dart`.
