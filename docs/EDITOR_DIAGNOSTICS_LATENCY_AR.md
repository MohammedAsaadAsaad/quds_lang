# سرعة التلوين والتشخيص أثناء الكتابة — 2026-11-17

متابعة بلاغ المستخدم بعد إصلاح الإكمال: التلوين واكتشاف الأخطاء يتأخران أيضًا.
الإصلاح السابق أزال المسح التربيعي والتوقف على مسار الإكمال، لكنه لم يختبر
استمرار الكتابة أو زمن أول تشخيص بوصفهما مرحلتين مستقلتين.

## الأسباب وما تغير

- كانت مهلة تجميع التعديلات تتجدد عند كل ضغطة، في الإضافة والخادم، ويمكن أن
  تؤجل الفحص طوال الكتابة المتواصلة. يبقى تجميع 75ms في الإضافة و120ms في
  الخادم، مع حد أقصى **للتأجيل** قدره 150ms و250ms على التوالي. هذه حدود
  لجدولة إرسال/بدء العمل، وليست ضمانًا لانتهاء فحص ملف مهما كان حجمه خلالها.
- كان التلوين الأول ينتظر استيراد المكتبات وفحص الأنواع واستعادة النص الناقص.
  يرسل العامل الآن ألوان التعريفات من AST نحوي مبكر، ثم يرسل نتيجة الفحص
  الدلالي الكامل. المرحلة المبكرة ليست إثباتًا لصحة البرنامج ولا تستخدم لبناء
  البرنامج أو لإعطاء الإكمال أنواعًا غير مفحوصة.
- تبقى ألوان الأسطر غير المعدلة ظاهرة فورًا عند التعديل؛ تحذف رموز الأسطر
  المتأثرة، وتتحرك رموز الأسطر التالية حسب الإزاحة الفعلية، بما فيها Unicode
  وتغييرات عدد الأسطر. تدمج التعريفات النحوية الجديدة مع الألوان الباقية بمرور
  خطي، ثم تحل نتيجة التحقق الكامل محلها. لا يعاد استعمال إحداثيات قديمة كما هي.
- يُنشر الخطأ الحقيقي عند اكتشافه، قبل محاولات استعادة سياق الإكمال. لا تُمحى
  أخطاء الدلالة لمجرد نجاح التحليل النحوي، ولا تُمحى الأخطاء بسبب نجاح تحليل
  نسخة معزول فيها السطر الناقص. اكتمال الفحص له العلامة qudsAnalysisComplete؛
  الاختبارات والمقاييس التي تحتاج الرموز الكاملة تنتظر هذه المرحلة تحديدًا.
- يعلن الخادم جاهزية الألوان المبكرة بإشعار quds/semanticTokensReady، وتطلب
  الإضافة التلوين لنسخة المستند المطابقة فقط. الإشعارات والردود تستخدم طابور
  كتابة موحدًا لمنع كتابة stdout أثناء flush؛ كشف اختبار stdio الحقيقي هذا
  التداخل أثناء إضافة النشر المرحلي، وأضيف الإصلاح إلى الحزمة نفسها.

تبقى حقيقة أخطاء اللغة وفحوص lowering وreadonly واختبارات المترجم كما هي.
الفحص الكامل ما زال يشمل الملف واستيراداته؛ لا ندعي بناء محلل أنواع تزايديًا
يعيد فحص دالة واحدة فقط. قد تزيد كلفة اكتمال الفحص بسبب مرحلة الألوان الإضافية؛
التحسين المقاس هو زمن أول لون/أول خطأ واستمرار العمل أثناء الكتابة.

## قياسات قابلة للإعادة

```sh
dart run tool/profile_diagnostics.dart
dart test test/editor_diagnostics_test.dart test/editor_growth_test.dart test/editor_test.dart --reporter expanded
node --check editors/vscode/extension.js
dart format .
dart analyze
dart test --reporter expanded
```

البيانات الخام: [editor_diagnostics.json](../bench/results/editor_diagnostics.json).
استُخدم بروتوكول الالتزام 5f8b9c5 للمقارنة، مع عبء العمل نفسه. القيم عينات
من جلسة LspSession حية وعامل منفصل، وتشمل مهلة الجدولة وبدء العامل لكل مستند؛
لا تشمل رسم VS Code أو نقل pipe. لا نقدمها حدودًا مضمونة لكل جهاز أو مشروع.

| الحالة | أول لون قبل | أول لون بعد | أول خطأ دلالي قبل | أول خطأ دلالي بعد |
| --- | ---: | ---: | ---: | ---: |
| 20 ربطًا | 117.633ms | 58.440ms | 140.907ms | 138.199ms |
| 5,000 ربط، نحو 10 آلاف سطر | 755.089ms | 305.358ms | 499.985ms | 361.025ms |
| 1,000 ربط واستيراد quds:math | 863.358ms | 65.322ms | 759.677ms | 391.292ms |

في عينة الكتابة المتواصلة، أُرسل 21 تعديلًا بفاصل 60ms: لم يصل أي فحص مكتمل
أثناء الكتابة قبل الإصلاح، ووصلت **3 فحوص مكتملة أثناءها** بعده. بقيت النتائج
مرتبطة بنسخة النص؛ لا تنشر نتيجة قديمة على أنها تخص النسخة الجديدة. يتأثر زمن
أول نتيجة بمدة التحليل الجاري والتنافس على المعالج، لا بالمؤقت وحده.

للشفافية، زمن اكتمال الفحص الأول للملف الكبير في العينة النهائية 900.382ms
مقابل 755.176ms قبلها، ولعينة math يبلغ 983.922ms مقابل 863.910ms. ظهرت
الألوان قبلهما بكثير، ووصل الخطأ قبل استعادة الإكمال، دون إسقاط فحوص البرنامج.
التوقيت الكامل لكل مرحلة مسجل في JSON.

## الاختبارات والتفعيل

اختبارات جديدة تثبت ترتيب الألوان/الخطأ/اكتمال الفحص، وتتحقق من نقل الألوان
فورًا عبر إدراج تعليق عربي وemoji وإسقاط ألوان السطر الجاري، ومن عدم تجويع
تشخيص ملف ثانٍ أثناء الكتابة في الملف الأول. اختبار الإضافة بساعة افتراضية
يثبت حد التأجيل واستخدام أحدث نسخة وإلغاء المؤقتات عند إغلاق الملف. اختبار
LSP عبر stdio يشغّل ملفات كبيرة مع تداخل الإشعارات والردود الفعلية.

لتفعيل الحزمة حدّث Quds والإضافة المثبتة معًا، ثم نفّذ **Developer: Reload Window**.
إعادة تشغيل الخادم وحدها لا تحمّل JavaScript الجديد لإضافة قديمة. الألوان
المبكرة تقديرية إلى أن يكمل الخادم التحقق، والتشخيصات المعروضة تصدر عن النص
الحقيقي، لا نسخة الاستعادة.

النتائج النهائية للفحص الشامل في [VALIDATION.md](VALIDATION.md).
