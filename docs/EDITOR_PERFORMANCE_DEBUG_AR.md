# سرعة المحرر والإكمال والتصحيح بقدس

تنفيذ طلب 2026-11-17. هذه تحسينات للمحرر والمصحّح، دون تعديل الصياغة المعتمدة للغة.

## المسار السريع

- يحتفظ خادم اللغة بتحليل الملف المفتوح. طلب الإكمال الحي لا يجري ترجمة متزامنة
  جديدة، ولا يقرأ مكتبة Dart ببطء كحل بديل قبل اكتمال التحليل الخلفي.
- يعمل التحليل في isolate منفصل طويل العمر. توجد مهمة واحدة قيد التنفيذ، وآخر
  طلب فقط لكل ملف في الطابور. لا يضيع الملف الأول عند فتح ملفين قبل جاهزية العامل.
  تُهمل نتائج النصوص القديمة، وتُزال المهام المنتظرة للملفات المغلقة.
- وضع `compile(..., emitDart: false)` يحتفظ بفحص الملف نفسه، بما فيه فحوص
  lowering وحدود readonly. يتجنب توليد حزم SDK وملفات الخرج وخرائط المصدر
  ونماذج الخرج غير اللازمة للمحرر. لا تُخفى أخطاء بناء الملف من أجل تحسين القياس.
- تجميع تغييرات الإضافة أصبح 75ms والتحليل الخلفي بعد سكون 120ms، بدل 200ms
  و300ms. طلب الإكمال نفسه يزامن النص فورًا، ولا ينتظر هاتين المهلتين.
- تُعلَّم النتائج غير الجاهزة `isIncomplete` ليعيد العميل طلبها، مع إعادة استخدام
  التحليل السابق فقط عندما يبقى السياق السابق للمؤشر متوافقًا.

## التغطية

الإكمال يشمل الأسماء المحلية والأنواع والدوال والأصناف والحقول والخواص والطرق،
والوراثة العامة في قدس وDart، وتسلسل الحقول إلى الحاويات، وامتدادات SDK العامة،
والمعاملات المسماة وكتل الاستدعاء ذات الإزاحة، والاستيرادات وsnippets الموجودة.
تتخصص تفاصيل `Parent<List<U>>` إلى `List<int>` عند استعمال `Child<int>`.
الأعضاء الخاصة في مكتبة مستوردة لا تظهر كأعضاء متاحة، وأسماء الأنواع الداخلية
للباكند لا تظهر بدل أسماء قدس العامة. الأسماء العربية مدعومة في الإكمال والتقييم.

أضيف `textDocument/signatureHelp`، ومزوّد VS Code المقابل، لعرض أسماء المعاملات
عند `(` و`,`، بما فيها الدوال العامة وتواقيع Dart المتاحة. يعرض التوقيع المعلومات
المعروفة في التحليل المخزّن؛ لا يشغّل محللًا ثقيلًا على مسار الكتابة الحي.

هذا ليس فهرسًا تلقائيًا لكل حزمة pub غير مستوردة. يعتمد إكمال الأعضاء على النوع
والمكتبات التي يعرفها التحليل؛ لا يمكن استنتاج كل أعضاء `dynamic` بصورة سليمة.
الملف المفتوح نفسه يُحلل من النص غير المحفوظ، بينما قراءة ملفات الاستيراد تتبع
آلية المترجم الحالية. لا ندّعي تكافؤ كل سياقات Dart/Flutter مع محلل Dart الأصلي.

## القياس القابل للإعادة

```sh
dart run tool/profile_editor.dart
```

النتيجة الخام: [editor_latency.json](../bench/results/editor_latency.json).
يقارن البرنامج عمليتين جديدتين لتحليل ملف يستورد `quds:math`، ثم يقيس 100 طلب
إكمال مخزّن بعد الإحماء، تشمل إنشاء الاستجابة وترميز JSON. هذه الجولة أُجريت
بالتزامن مع الفحص الشامل، ولذلك تتأثر أزمنة البداية بالتنافس على المعالج.

| المرحلة | النتيجة المسجلة |
| --- | ---: |
| ترجمة كاملة، عينة بداية واحدة | 3687.790ms |
| تحليل محرر مع فحوص الملف، عينة بداية واحدة | 1627.528ms |
| جاهزية العامل الخلفي، بما فيها بدء isolate | 1623.502ms |
| عدد اقتراحات الطلب | 623 |
| الإكمال المخزّن p50 | 3.237ms |
| الإكمال المخزّن p95 | 6.984ms |
| أكبر عينة إكمال | 19.134ms |

هذا قياس لخادم اللغة وترميز الاستجابة، لا لزمن رسم VS Code أو نقل البيانات عبر
قنوات النظام أو بدء عملية Dart نفسها. أزمنة البداية أعلاه عينات منفردة، وليست
ضمانًا ثابتًا أو مقارنة أداء مستقلة عن الحمل. لا تُفرض حدود توقيت هشة في CI.

## نقاط التوقف وقيم المتغيرات

كشف الاختبار الحقيقي أن إضافة imports والمساعدات إلى Dart كانت تزحزح الشيفرة
دون تحريك خرائط المصدر. أُصلح حساب الإزاحة، وكذلك إزاحة تعليقات تجاهل تحذير
const غير المستعمل. يُختبر أن سطر breakpoint يقابل تعليمة `print` نفسها.

المصحّح يعرض مسار `.quds` وسطره، ويعيد أسماء المتغيرات الأصلية، وينقل خريطة
الأسماء عند توسيع قيم متداخلة. تعود تعبيرات `evaluateName` الخاصة بـWatch إلى
أسماء قدس، ثم يترجم التقييم الاسم الصحيح ضمن النطاق. تبقى قيم المستخدم النصية
كما هي؛ لا يُستبدل محتوى السلاسل النصية لإخفاء أسماء الباكند.

اختبار DAP فعلي يبني برنامج قدس، يوقفه على السطر 7، يقرأ القائمة `القيم`،
يوسع عنصرها ثم حقل `value`، ويقيّم `القيم[0].value` إلى `41`.
اختبار التوقف البسيط وقراءة المتغيرات والتقييم السابقان يظلان ضمن الفحص الشامل.
تستخدم عمليات التنفيذ VM وDAP الفعليين؛ اختبار تحويل مزوّد التواقيع في الإضافة
يستخدم stub لـVS Code، ولا يُقدَّم على أنه اختبار مرئي لواجهة المحرر.

## استعمال التحديث

حدّث المستودع وإضافة Quds المثبتة، ثم نفّذ **Developer: Reload Window** لتفعيل
تغييرات JavaScript في الإضافة. يمكن إعادة تثبيتها عبر `quds install` من النسخة
المحدّثة، أو **Developer: Install Extension from Location** واختيار
`editors/vscode`. أمر **Quds: Restart Language Server** يعيد تشغيل الخادم.
ضع breakpoint في هامش ملف `.quds` ثم F5، وافتح Variables وWatch لتوسيع القيم.

نتائج التنسيق والتحليل والفحص الشامل النهائية في [VALIDATION.md](VALIDATION.md).
